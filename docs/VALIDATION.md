## 发布前复查修正

- 按 SDL 两类手柄驱动对照，修正 Pro IMU 的三轴顺序与正负方向：Pro = (-DS.z, -DS.x, DS.y)，先在 DS 坐标内应用真实校准。
- 实现 IMU 量程子命令并拒绝无效参数；关闭后重新启用恢复默认量程。
- 使用带 USB 复位代数的输出队列，避免复位前已取出的命令在新会话执行。
- 手柄断线时归零旧触觉与校准，恢复精确摇杆中心。
- 配置页在读完全部必需报告后才启用保存；阻止重读失败后使用旧缓存。
- Windows 构建对无效板型/USB 速度、复制错误和刷写错误返回失败。
- 添加固定依赖的软件 CI；其结果仅覆盖软件行为，不表示硬件验收。
