# Pro2 功能清单（alpha.11 / Pro-dev1 r10）

本版为 LCTech BL616 Full-Speed 本地测试固件，尚未刷入接收器或接入 NS2 验收。“已实现”表示代码与软件测试通过，不代表本接收器已通过主机验证。NS1 仍只以纯 Pro（模式 3）为目标；Pro2 为模式 6。

| 功能 | r10 状态 |
|---|---|
| USB 身份、原生配对挑战、初始化 | 保留 r8 实现；本板主机识别仍待测 |
| 按键、摇杆、C 键 | `05/09` 两套报告；DualSense 静音键映射 C |
| GL / GR 背键 | Edge 左右背键分别映射；普通 DualSense 无独立背键 |
| 主机 `09` 体感 | 新增 30 字节原生姿态 PDU，包含四元数与加速度；新鲜采样和源时间戳驱动，断线重置 |
| 电脑 SDL `05` 体感 | 保留三轴陀螺仪、加速度、时间戳 |
| 电量 / 玩家灯 | 修正 `09` 电量等级；主机玩家分配映射 DualSense 玩家指示灯 |
| 基础震动 | 已知 `0x5` 单帧格式，兼容 42/64 字节包；左右独立强度转换，非完整 HD Rumble 2 |
| 校准存储 | 用户区 128 字节限界读写、跨 USB 包接收、工厂区只读；NVS 保存路径已加入，实际掉电保持待测 |
| 耳机 / 扬声器输出、麦克风输入 | 未实现；Pro2 没有音频设备，不能替代 Pro＋麦克风 |
| 完整 HD Rumble 2 | 未实现频率波形与所有打包格式 |
| NFC / Amiibo | 未实现；DualSense 无实体 NFC，软件虚拟标签也尚未移植 |
| 唤醒、直连主机蓝牙、原装固件更新 | 未实现 |

## 有主机实测记录的参考

r8 使用 PicoSwitch2 v1.3.0 的身份和配对实现。r10 进一步对照其较新提交 [`e054bfd1311289f392069ff0d2447e01748c2124`](https://github.com/notsosaelin/PicoSwitch2/tree/e054bfd1311289f392069ff0d2447e01748c2124)，移植 Apache-2.0 的 [DualSense 姿态编码](https://github.com/notsosaelin/PicoSwitch2/blob/e054bfd1311289f392069ff0d2447e01748c2124/firmware/src/motion/ns2_ds5_motion.c)及 PDU 子集。该项目的 [STATUS](https://github.com/notsosaelin/PicoSwitch2/blob/e054bfd1311289f392069ff0d2447e01748c2124/STATUS.md)记录真实 NS2 /《喷射战士3》的 0x1E 体感验证；其试验性的 0x28 编码没有采用。项目硬件、USB 栈与本板不同，参考项目成功不等于本板通过。

转换先使用 DualSense 工厂校准，再采用最新参考代码的 `[X,-Z,Y]` 坐标旋转与源传感器时钟。重复 USB 轮询不会重复积分旧采样。软件测试覆盖静止、慢漂、快速转动、姿态跨区、时间戳回绕与断线复位；仍需实机判断方向、灵敏度和延迟。

## 音频为什么还不能直接加入

当前 BL616 USB 驱动的四个 FIFO 已分配给 HID OUT、Bulk IN、Bulk OUT、HID IN；同编号两个方向不能直接复用。只加入麦克风就需要第五个独立传输方向，双向耳麦需要第六个。需要进一步改造 USB 驱动/端点调度或硬件方案，不能只追加音频描述符。参考项目在 Pico2W 上的声音输出不构成本板可直接复用的证据，且它的 DualSense 麦克风返回也未完成。

## 本地验收

关闭模拟器后刷入本板固件，拔插并从配置页确认 `Pro-dev1 r10`，再选择 Pro2、保存并重新授权。先在电脑检查逐键、C/Edge 背键及源 IMU，再在 NS2 完成 L/R 注册、三轴体感、左右震动、玩家灯、连续游戏和睡眠重连测试。不要只凭电脑网站识别判断主机支持。

用户校准仅允许 `0x1FC000–0x1FC07F`，约每秒尝试保存到 NVS；写入 ACK 后立即断电可能尚未落盘。保留工厂区写保护。完整软件验证与镜像校验值见 [VALIDATION.md](VALIDATION.md)。
