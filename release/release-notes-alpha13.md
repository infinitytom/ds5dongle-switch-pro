本版新增固定模式组合键与网页自动连接。固件版本：**Pro-dev1 r12**。

### 固定组合键

同时长按 **PS + Options + 下列按键 2 秒**，直接切换目标模式：

| 按键 | 模式 |
|---|---|
| × | DS5 |
| ○ | DualSense Edge |
| □ | Auto |
| △ | Switch Pro |
| ↑ | Pro + USB 麦克风 |
| → | Xbox + 音频 |
| ↓ | Pro 2（实验） |

- 保存成功后自动重启，保存失败保持原模式；选择当前模式不重启。
- 每次切换后松开 PS 和 Options；上电按住或输入中断时不会连续触发。
- 同时选择多个目标或斜方向无效，中途更换目标会重新计时。
- 组合键在按键映射前识别，拦截相关面键、方向键和 PS/Options，并取消 Windows 游戏栏快捷键调度。

### 网页自动连接

打开离线配置页、重新插入接收器或通过组合键切换模式后，网页会自动连接已授权的配置接口。首次使用或新的 USB 模式身份仍需点击连接按钮授权；浏览器授权无法由网页自动代替。多接收器时自动选第一个可用配置接口，也可手动选择。页面新增快捷键对照表，连接后显示实际模式。
