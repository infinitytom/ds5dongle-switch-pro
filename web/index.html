DualSense · Edge · Switch Pro

● 本地离线运行

尚未连接接收器

使用桌面版 Chrome 或 Edge，通过 USB 连接接收器。

Switch Pro 为实验模式：主机需开启「Pro 手柄的有线通信」。○ → A，× → B，△ → X，□ → Y，PS → HOME，触摸板按下 → 截图。高清震动、体感方向和 Switch 1/2 兼容性仍需实机验证；不提供 NFC、主机唤醒或 HD Rumble 2。

接收器设置

读取后可编辑。USB 模式、序列号等设置需要保存并重启后生效。

按键映射

映射先作用于 DualSense 按键，再转换为 Switch 布局。支持两组游戏手柄按键配置；键盘/鼠标目标仅在 DS 模式有效。
